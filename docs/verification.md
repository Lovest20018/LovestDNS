# 验证范围

公开仓库保留可复现的测试程序、构建检查和 API 合成样例。真实主机的验收报告、实例标识、数据统计及迁移备份不作为公开源码发布。

本项目包含 Debian 原生安装/升级/回退、隔离容器验收、DNS 协议查询、配置历史及条件写入、缓存保留与故障回退测试。执行方式见[开发说明](../integrated/README.md)，安装和兼容性要求见[原生部署说明](lovestdns-native-deployment.md)。一次部署的成功不代替其他架构、网络、旧数据版本和长期负载验证。

API 样例使用人工构造的数据和公开保留地址，经真实处理函数产生，来源与校验方式见 [v1 契约](contracts/v1/README.md)。
