# LovestDNS v0.2.2

本次更新适用于 Debian 12/13 amd64 原生部署及从源码构建的集成容器。

## 控制台与查询记录

- 侧栏统一为概览、域名分流、查询与诊断、广告过滤、维护和系统设置。域名分流顶部显示当前列表，现有深链接可继续使用。
- 查询记录和拦截记录支持原位展开详情。历史结果按同一查询快照分页，便于继续检查同一批记录。
- 可以在「系统设置 → 来源设备」为来源 IP 设置备注。开启查询记录后，可在查询记录和来源排行中按设备识别来源。
- 「系统设置」集中管理运行参数、配置和软件更新。网关联动按实例状态显示入口。

## 广告过滤

- 订阅可作为拦截列表或白名单。白名单支持常用域名规则，命中后继续走当前 DNS 解析链，可在域名检查和查询记录中查看命中来源。
- 订阅刷新后可以复核变更，刷新失败时保留上一份生效规则。支持的语法与操作见[广告过滤说明](../dns-filtering.md)。

## 安装与升级

从 v0.2.1 升级时，在旧版的「维护 → 软件更新」检查正式版。升级后入口为「系统设置 → 软件更新」。也可下载本次发布附带的安装器，执行 `sudo python3 install.py --version 0.2.2`。命名实例请带上原有的 `--instance` 参数。

升级会备份配置和数据，并短暂重启服务。[安装、校验和回退说明](../lovestdns-native-deployment.md)
