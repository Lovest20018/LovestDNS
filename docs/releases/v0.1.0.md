# LovestDNS v0.1.0

首个正式发行版，面向 Debian 12/13 amd64、systemd 的小规模家庭与局域网 DNS。[GitHub Release](https://github.com/Lovest20018/LovestDNS/releases/tag/v0.1.0)。

## 本版内容

- DNS 服务、组件、缓存、解析诊断和有界查询记录。
- 网页规则编辑、配置历史、差异、受控应用与正常失败回退。
- 软件更新独立任务、归档与包内校验、HTTP CONNECT/SOCKS5 专用代理。
- 默认只检查正式版，预览版需在“更新网络与通道”主动选择；不自动安装更新。
- 整理项目和文档入口，归档历史方案与实验，移除已停用的旧概览页及构建兼容分支。

独立 DNS 部署无需网关或 Docker。外部 Token API 和查询记录均默认关闭。旧候选版本可使用随附安装器迁移，保留实际实例名；旧版无法直连 GitHub 时先通过已校验归档迁移，再配置更新代理。

## 制品与验收

本版使用规范版本号 `0.1.0`，GitHub 发行标记为正式版，并设为最新正式发行版。代码与前端来自固定提交 `959f384deffddcea82b146d1bca67a59c7255ceb`；文档后续补充不改变安装包。

## 范围与限制

正常安装、升级、代理失败处理和回退按最终制品验收。强制终止/断电全阶段恢复、自动备份保留和更大规模长期负载仍在后续工作中；详见[已知限制](../roadmap.md)。不宣称全面性能提升，不自动调整主机内存参数或升级任何在用实例。
