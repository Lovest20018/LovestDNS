# LovestDNS v0.1.1

适用于 Debian 12 和 13 的 amd64 systemd 部署。[GitHub Release](https://github.com/Lovest20018/LovestDNS/releases/tag/v0.1.1)

## 控制台

- 概览显示 DNS 进程、配置记录和维护任务。“测试本机解析”逐条显示样本域名的应答、耗时及采样时间，配置加载前的结果会标为历史。
- 规则编辑器在保存处提供下一步操作，并在能够确定目标域名时预填样本查询。只打开缺失文件的模板时可以继续其他维护操作。
- 重启和分流应用在操作区显示提交、执行和恢复结果。普通 HTTP 下支持幂等提交。响应丢失后按原请求编号核对，明确拒绝且无受理记录时可以继续操作。
- 配置历史、任务、软件更新与日志集中在“维护”。更新通道和代理移到“设置”，TTL 规则归入“解析配置”。

## 安装与升级

原生安装器允许在首次启动失败后重试同一版本。重试会保留先前导入的数据。升级前会备份配置和数据，新版本须通过就绪检查与 DNS 应答探测。已安装 v0.1.0 的用户可以在“设置 → 服务信息 → 软件更新”升级，或通过命令行传入已校验的安装包。[安装、升级与回退](../lovestdns-native-deployment.md)

本版沿用 v0.1.0 已核验的 DNS 组件与离线 Python 依赖。归档、SHA-256 校验文件、独立安装器和升级说明随同一 Release 提供。
