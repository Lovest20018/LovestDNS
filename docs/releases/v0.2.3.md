# LovestDNS v0.2.3

本次更新适用于 Debian 12/13 amd64 原生部署及从源码构建的集成容器。

## 软件更新与控制台

- 软件更新页显示当前版本、更新通道和最新发布。网页仅允许升级到更高版本，主机执行更新前会再次核对版本。
- 登录页改善密码管理器兼容性、键盘操作、文字对比度和窄屏布局。
- 下拉与折叠控件补充方向提示，移动端菜单和刷新使用常见图标。清空记录、移除订阅和清除网关凭据用危险操作样式标识。

## 查询记录与原生维护

- 关闭查询记录后保留已有历史并停止写入在途批次。查询记录增加并发写入、存储容量和历史过期处理的回归检查。
- 原生升级成功后按保留策略清理旧备份、版本和安装收据，保护当前回退点及仍被引用的版本。可以先用 `sudo lovestdnsctl prune --dry-run` 查看清理范围。
- 原生安装包保留启动入口实际使用的 Redis、Unbound 和 DNSCrypt 二进制，移除多余副本。
- 更新 Alpine OpenSSL 和 Expat 的构建依赖锁定版本，恢复源码打包。

## 安装与升级

从 v0.2.2 升级时，可在「系统设置 → 软件更新」检查和确认最新正式版，也可下载本次发布附带的安装器，执行 `sudo python3 install.py --version 0.2.3`。命名实例请带上原有的 `--instance` 参数。

升级会备份配置和数据并短暂重启服务。需长期留存的历史备份请在升级前转存。[安装、校验和回退说明](../lovestdns-native-deployment.md)
