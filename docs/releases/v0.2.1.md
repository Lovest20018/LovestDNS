# LovestDNS v0.2.1

本次更新调整集成版的首页、拦截记录和广告过滤管理界面，适用于 Debian 原生部署及从源码构建的集成容器。

- 宽屏首页将解析指标与查询趋势并排展示。来源和域名排行默认展示前五项，可展开其余条目。
- 展开拦截记录即可看到命中规则及来源。查询和应答分组排列，完整活动版本按需展开，手机端使用单栏。
- 「订阅与规则」集中显示过滤状态、规则数和活动版本。宽屏可并排编辑本地规则和管理订阅。待复核预览位于订阅列表顶部，刷新、设置和移除操作按订阅归组。

已有 Debian 原生实例可在「维护 → 软件更新」选择正式版。命令行升级可使用本次发布附带的安装器执行 `sudo python3 install.py --version 0.2.1`。命名实例请加原有的 `--instance` 参数。升级过程会备份实例并短暂重启 DNS。[安装与升级说明](../lovestdns-native-deployment.md)
