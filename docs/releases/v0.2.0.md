# LovestDNS v0.2.0

适用于 Debian 12 和 13 的 amd64 systemd 部署。

## 广告过滤与查询记录

- 在「广告过滤」预览订阅、核对无法导入的行并应用。MosDNS 分流入口支持精确域名、后缀、例外、阻断型 hosts 行和受限的字面片段匹配。纯递归入口继续使用原有解析路径。[过滤语法与限制](../dns-filtering.md)
- 在首页查看最近 1 小时或 24 小时的解析情况，按设备来源查看历史。展开已确认的拦截可看到规则、订阅和活动版本，并对该域名临时放行。查询记录沿用实例已有开关。
- 首页的「全部拦截记录」在原处展开，支持在选定时段内翻页和收起。侧栏的「广告过滤」位于「查询与诊断」之后，配置、诊断、维护与设置共用分区标题、页签和表格样式。
- 本地规则草稿支持跨页保留。遇到并发修改时可以核对当前规则，再决定是否应用。精确放行复用已编译的订阅规则，最近拦截查询优先读取拦截记录索引。
- 设备接入页提供指定入口和设备默认 DNS 两组查询命令，各有独立查询名，可跳到相应的入口记录。首页收起详情后停止读取其中的配置状态，暂停刷新时继续跟踪活动维护任务。

## 安装与升级

已有原生实例可在「维护 → 软件更新」选择正式版更新。命令行使用本次 Release 附带的安装器执行 `sudo python3 install.py --version 0.2.0`，命名实例须加上原来的 `--instance`。升级会备份实例数据并短暂重启 DNS。

手工回退会在停服前准备备份副本。目录切换或恢复后的健康检查失败时，安装器尝试恢复切换前的数据、配置和服务。回退需要预留容纳备份副本的磁盘空间。[安装与回退说明](../lovestdns-native-deployment.md)
