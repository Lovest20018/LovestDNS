# 解析概览与 DNS 过滤

## 从概览查看查询

在「查询与诊断 → 查询记录」开启采集。记录默认关闭，最多保留 24 小时、10 万条，并受数据库容量限制。关闭采集后，仍可查看保留期内的记录。

首页「解析概览」提供最近 1 小时和 24 小时两个窗口。点击查询量图的时间桶可以查看该时段，再点击一条记录的来源 IP 缩小范围。点击域名排行使用精确匹配，查询日志中的手工域名筛选使用包含匹配。点击某条日志的域名即可展开请求、响应和耗时。

图表统计保留的入口事务。来源 IP 以服务端看到的地址为准，路由器代转时可能只出现一个地址。图表标明采集缺口。P95 取有应答的耗时样本，并显示样本数和采集口径。旧记录、过期或清空后的窗口可能处于覆盖未知状态。

## 启用 DNS 去广告

从一级导航打开「广告过滤」。默认的「拦截记录」可检查域名、展开历史命中并放行。「订阅与规则」管理开关、本地规则和两种订阅，「放行列表」管理全实例的精确放行与白名单订阅。首页的「最近拦截」和「来源 IP 排行」沿用选中的时间窗口。采集关闭时仍可查看保留期内的历史。

功能默认关闭，启用时会在 MosDNS 读取缓存之前检查请求域名，命中后回复 REFUSED。纯递归模式由 Unbound 直接接收查询，提供解析概览与日志。分流模式恢复后，已保存的过滤规则随 MosDNS 加载。

可以粘贴本地规则，或填写 HTTPS 订阅的名称、地址和刷新周期。先获取预览，再应用订阅。预览列出有效、重复、无效和不支持的规则，并提供最多 100 条问题行。部分导入需要确认。遇到无法保留语义的例外、禁用规则或预处理指令，候选版本无法应用。刷新失败时仍使用上一活动版本。软件更新代理和订阅下载分别运行。

| 本地规则与拦截订阅的语法 | 作用 |
| --- | --- |
| `ads.example.test` | 精确拦截该域名 |
| `*-ad.example.test*` | 在查询名中匹配固定文本 `-ad.example.test`，忽略大小写，点按字面匹配。文本前后均允许额外字符。 |
| `\|\|ads.example.test^` | 拦截该域名及其子域 |
| `@@\|\|ok.ads.example.test^` | 放行该域名及其子域，再按现有策略解析 |
| `0.0.0.0 ads.example.test`、`127.0.0.1 ads.example.test`、`:: ads.example.test` | 导入 hosts 阻断行，对每个名称做精确匹配 |
| `!` 或 `#` 开头 | 普通注释 |

域名采用 ASCII 或已编码的 IDN A-label。两端各一个星号的固定片段支持字母、数字、连字符和标签间的点，活动规则最多含 128 个不同片段。其他通配、正则、元素隐藏、指定 IP 的 hosts 重写和 `$client`、`$dnsrewrite` 等扩展语法会在预览列出。已有秋风订阅升级后可点「刷新订阅」，复核新增的匹配类型，再点「应用订阅」。确认前继续按原版本过滤。[AdGuard DNS 官方规则语义](https://adguard-dns.io/kb/general/dns-filtering-syntax/)

### 白名单订阅

从「放行列表」添加白名单，或在「订阅与规则」选择白名单类型。预览显示两种匹配范围。启用后，匹配的请求先放行，再进入当前 DNS 解析链。旧订阅按拦截类型加载，原有的域名例外继续生效。

| 已覆盖的白名单规则 | 匹配范围 |
| --- | --- |
| `exact.example.test` | 精确匹配该域名 |
| `\|\|allow.example.test^` | 匹配该域名及其子域 |
| `@@\|\|allow.example.test^` | 匹配该域名及其子域 |

正则、带客户端条件或应答重写的规则会列入预览问题行。编译时整行跳过这些规则。允许部分导入时须先确认。查询记录和当前规则检查显示命中的订阅标识、名称、规则原文与版本。手工精确放行、多个白名单订阅和本地例外可以重叠，移除或停用任一来源后重新计算活动规则。

## 核对误拦截并放行

「检查当前规则」读取 MosDNS 当前加载的规则版本，查询记录关闭时也可以使用。查询记录展开后，已采集的事件会显示订阅、规则原文和请求当时的版本。普通上游返回 REFUSED 时仍显示其原响应码，过滤判定按核心事件另行展示。

在已拦截详情中点击「精确放行 10 分钟」或「永久放行此域名」，也可以在「放行列表」输入尚未查询过的域名。精确放行作用于整个实例的该域名。待界面确认版本应用后，可点击「重新查询」验证 DNS 应答。临时放行到期后由 MosDNS 在下一次查询时恢复原过滤判定。已保留的旧记录会继续显示当时的判定。可以在过滤页移除精确放行。

集成版使用绑定到实例的本地控制与事件套接字。旧包可以继续使用原来的报文采集方式。启用过滤需要包含对应 MosDNS 扩展的包或 Docker 候选镜像。[构建说明](../integrated/README.md) · [实施方案](dns-analytics-and-filtering-plan.md)
