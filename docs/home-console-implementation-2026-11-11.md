- 新增可选 `runtime.dns`：从 Linux `/proc` 获取进程持有的监听 socket，并与生成配置中的 DNS 监听字段匹配，排除 HTTP 指标和控制端口。读取有大小、文件描述符和端点数量上限；PID/启动标识变化、权限问题或未知配置均返回未确认，不影响既有健康和缓存统计。
- 诊断页的通道预设来自新鲜监听采集；不再默认猜测递归端口 5301。通配地址仅在服务内部主动诊断时转为回环地址，首页不将它当作客户端接入 IP。IPv6 地址保留地址族；没有接口作用域的 link-local 地址不加入预设。

## 监听数据边界

该字段描述服务网络空间中、采集时由进程持有且匹配当前生成文件的 socket；不证明所有生成规则已加载，也不确认容器宿主机端口映射、NAT/重定向或真实终端路径。生成配置使用未知语法/引用、或无法读取时，不猜测缺失的端口。旧采集器没有这个字段时，前端仍能工作，显示监听未确认。

当前只解析 MosDNS 的 udp_server/tcp_server 字面监听参数，以及 Unbound 生成主文件的 server.port/interface。未展开任意 include、环境变量或主机名；特殊配置可能只显示部分已匹配监听或没有可用目标。设备历史、全入口延迟分布和实际请求分支仍属于后续阶段。
