对应 [交互、UI 与程序优化方案](ui-interaction-review-2026-11-06.md)，实现位于当前工作区，保留进入本轮前已有的未提交改动。独立版 `web/` 保持冻结。本轮不发布版本、不升级生产实例。

## 已实现

| 范围 | 实现与用户可见结果 |
| --- | --- |
| 配置写入恢复 | 写入监听文件前，先在 SQLite 提交包含原文和候选内容的意图记录。文件写后历史记录、裁剪或事务失败返回 `503 / SAVE_UNCONFIRMED`，不再把结果描述成确定的失败。下次文件/历史读取或写入时核对磁盘，完成历史记录；保留第三方新版本及候选版本，不自动覆盖外部编辑。原地写入保留 inotify 行为，精确写 UTF-8 字节，修复空文件恢复。维护锁冲突返回 409。 |
| 维护任务 | 相同动作合并时也持久记录每个请求编号；合并编号至少保留七天。领取失败可恢复，领取提交结果不明时标记中断并禁止重放；执行结果入库失败仅重试入库，动作不会再次执行。能力接口反映工作线程及日志状态，执行器不可用时拒绝新动作。 |
| 编辑与草稿 | 所有文件编辑入口共用内存文档、读取版本和条件保存；跨路由与会话恢复保留草稿，基础设置和高级配置的 custom_env 共用内容。显式退出清除本轮内存草稿，实例切换隔离文档并拒绝旧请求写回。配置不再经 Zustand persist 写入 localStorage。旧版本缓存不再读取，也不自动删除旧草稿。 |
| 文档保真 | 文本/可视化切换不重写文件；域名规则保留空行、注释与未编辑行，TTL 不再强插说明头，保留自定义注释。环境变量保留行映射；YAML 通过文档节点编辑保留注释，未知嵌套结构阻止可视化覆盖并提供原文入口。新建和临时未填写完整的行仍可编辑，保存时校验。 |
| 请求与状态 | 组合调用者取消与默认超时；响应结构校验，保留错误码和请求编号；并发 401 仅触发一次恢复。写操作超时明确标记结果待核对。运行环境失败会清除旧值；TTL 使用与基础设置一致的运行环境。暂停保留带时间的历史样本，明确标记历史状态，不再报采集故障。 |
| 刷新与渲染 | 能力/环境从每五秒改为约三十秒，运行样本约五秒；隐藏时暂停后台轮询，重新可见时更新。配置状态约三十秒，任务活动时约三秒、空闲约二十秒；手动与自动读取去重，保存和任务完成定向失效。权限/环境 Context 与采样 Context 分开，编辑页不订阅每轮采样。 |
| 交互与布局 | 保存无修改时禁用，编辑后清除旧成功反馈；保存结果及下一步集中到文件工具区。基础设置增加源文件入口。TTL 编辑前置、说明折叠及局部表格滚动，手机分流文件采用紧凑标签网格。状态页趋势前置，组件详情在后；异常组件直达对应日志，规则行可带域名进入查询。诊断保留旧结果，新增链路对照摘要，技术标记默认折叠。账户操作集中到菜单，手机主要控件至少 44px。 |
| IPC、采集与备份 | manager 最多八个并发本地请求，超出快速返回忙；写操作继续使用单执行器及跨进程锁。采样速率、调度使用单调时钟，慢轮次跳过追赶；快照时间等待有上限。原生重启备份改为 64 KiB 分块复制、SHA-256 校验和小型清单；停止服务前完成校验，恢复前再次全量校验，保留最近两代备份，不再构造全量 bytes/hex JSON。 |
| 构建 | 前端覆盖层拥有显式 API/store 适配；每次重建清理生成源码，依赖缓存独立保留，删除的页面不会残留。产物附带源码提交、工作区状态、锁文件摘要、Node 版本及文件摘要。九个路由延迟加载，页面错误边界支持重试且保留内存草稿。 |

python -m pytest web/backend/tests -q
node --experimental-strip-types --test integrated/frontend/tests/*.test.ts
node --experimental-strip-types --test web/tests/*.test.ts
python scripts/build-integrated-ui.py --reuse-dependencies

## 验收边界

最初 Windows 验证覆盖 Python 文件/SQLite 异常、任务执行器、流式备份与回退逻辑；浏览器使用合成组件状态和 DNS 应答。随后通过 MCP 完成 [第一轮 Linux 实机验收](linux-optimization-validation-2026-11-06.md)：真实核心应用与重启、失败回退、进程终止、独立 tmpfs 磁盘耗尽和短时并发测试通过。后续完成 180 秒持续慢诊断、CPU/RSS 测量以及测试实例的安装器显式/自动回退，见下方后续记录；未操作生产回退，未扩展为生产长时间 soak。

诊断请求跨 worker 容量控制、预览零等待准入、RSS/CPU/慢查询测量和按 cgroup 当前使用量计算缓存预算，已在后续完成，见 [剩余优化验收](optimization-followup-2026-11-06.md)。缓存预算在初始化/重启时调整；当前不引入 WebSocket 或完整服务重写。旧 localStorage 草稿保留原键且不再读取，用户如需恢复应先导出原值；新实现仅在当前标签页生命周期中保留草稿，刷新/关闭页面仍弹出未保存提醒。
