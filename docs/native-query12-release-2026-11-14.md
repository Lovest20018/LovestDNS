## 功能变化

- 默认关闭、有界保留、仅管理员可查看的真实入口查询记录，以及慢入口检查造成误判时钟跳变的修复。
- 查询记录、主动查询、链路对照分区；首页直接到查询表单，记录行可带入域名与类型。
- 暂停自动刷新与后台记录分别表达，各页可恢复刷新；HTTP 复制有成功反馈和手动选择／下载回退。
- 筛选、分页与页签可通过链接恢复；手机采用记录卡片；明暗主题链接与键盘焦点改善。

## 同包验收与公开下载

同一份上述摘要的归档通过隔离原生干净安装与 home2.1 升级，核对包内载荷、外层安装收据、实例身份、配置保留、实际监听和前端来源。实际运行源码的时钟诊断覆盖慢检查与真实正负时钟跳变。

升级验收完成 23 个功能阶段，显式回退恢复旧收据、缓存及数据；内部校验损坏的包在进程切换前被拒绝；有效但故意无法启动的测试载荷触发自动恢复。两个成功验收分别完成 33 次记录检查，另有 434 次缓存、协议及分流查询，合计 **500 次明确计数查询通过**，不含原生 smoke 额外查询和准备失败轮次。

原生验证的三轮运行共 93 次既有服务健康探测无失败，配置与服务身份前后指纹一致。测试实例、网络命名空间和限容临时挂载已移除；95 个私有证据文件在导出后独立校验，查询数据库完整性、权限、清空后保留及回退归档中的记录数均已复核。

## 使用此版本

从本次 Release 下载 `install.py`。首次安装先准备私有配置：

```sh
sudo python3 install.py --version 0.1.0-dev.lovestdns-native.20261114.query1.2 --config ./lovestdns-install.env
```

既有命名实例升级：

```sh
sudo python3 install.py --version 0.1.0-dev.lovestdns-native.20261114.query1.2 --instance <实例名>
```

默认实例省略 `--instance`。既有实例不传配置时保留原配置；升级前确认备份与空间，操作流程见[原生部署说明](lovestdns-native-deployment.md)。本次发布没有自动升级已有试用实例。

本次是功能与发行验收，不代表修复后已完成长期稳定性、真实终端接入或新旧整链性能验收。查询记录仍遵守管理员权限和 24 小时／100,000 条及存储容量上限；缓存命中和实际逐请求分流保持未知。
