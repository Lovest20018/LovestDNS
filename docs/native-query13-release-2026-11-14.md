## 更新机制与验证范围

网页更新仅接受已修改初始密码的管理员会话与 CSRF，外部 Token 无更新权限。不接受任意下载 URL、命令或实例参数。确认绑定精确版本和摘要，安装前重新核对官方 GitHub 发行信息、归档和包内文件。独立 systemd 更新进程负责安装，不随 DNS/Web 重启而结束；任务与结果位于本机私有更新目录，回退数据时仍保留结果。下载临时清理，安装日志保留最近五份。配置和维护写入在升级期间暂缓，现有配置、数据及服务单元先生成一致备份，启动失败时尝试恢复原版。

- 锁定依赖的 `npm ci`、审计、TypeScript/Vite、ESLint、前端测试、API 契约检查及公开隐私扫描通过。桌面、手机、明暗主题、取消确认、断线重连和重新进入读取结果完成浏览器走查。
- 同一发行归档在隔离 Linux 网络命名空间中完成干净安装、实际升级、显式回退、内层坏包拒绝及启动失败恢复。缓存、协议、分流与查询采集明确计数 500 次；采集源码的慢检查及真实正负时钟跳变回归通过。
- 真实 systemd 更新助手通过实际浏览器会话接口提交任务，在合成发行信息与下载边界下完成启动失败自动恢复、成功升级和显式回退；实际校验、备份、安装器、systemd 服务、健康检查与结果恢复使用发行代码。该用例使用测试候选版本，不把模拟下载当作真实 GitHub 验证。
- 完整 [Linux CI](https://github.com/Lovest20018/LovestDNS/actions/runs/43547344831) 和 [公开隐私检查](https://github.com/Lovest20018/LovestDNS/actions/runs/43547344806) 通过，包含 Windows 环境曾超时的 UDP 用例、组件/缓存兼容及容器运行验收。
- 首次隔离运行因旧测试脚本仍等待 query1.2 而超时；失败记录保留并修正版本断言后，使用同一归档重新验证，未把该失败计为通过。完成后移除测试实例、helper unit、命名空间与临时挂载，原有服务及配置保持不变。
