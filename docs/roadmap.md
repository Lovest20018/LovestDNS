# 已知限制与后续工作

v0.1.0 正式发布面向 Debian 12/13 amd64 的小规模家庭与局域网 DNS，提供当前已验收的配置、观测、软件更新和正常失败回退能力。正式发布不代表所有网络、数据版本、故障方式或长期负载均已覆盖。

## 运维与故障恢复

- **异常中断**：软件更新结果会重新核对实际版本、安装收据和健康状态，不自动重放安装；规则加载失败会尝试恢复旧文件及运行配置。强制终止或断电不会执行所有异常处理，多文件规则替换和安装各阶段的事务恢复仍需完善。恢复失败时按[主机回退流程](lovestdns-native-deployment.md)处理。
- **备份空间**：当前安装器在停止 DNS 前检查空间，保留升级备份；自动保留策略尚未提供。主机应至少保留当前可用回退材料，定期核对磁盘，不要删除 `rollback.json` 正在引用的备份和程序版本。
- **组件资源**：内存预算和主机参数需要结合实际机器。发布包不会自动提高缓存、增加线程或修改主机 overcommit/透明大页设置。

后续将补齐持久事务日志、各阶段强制中断验证、受引用保护的备份保留策略和容量展示。

## 观测与使用规模

- 查询记录默认关闭，可按来源 IP 观察，但不保证一个 IP 永远对应同一设备。
- 逐请求缓存层、上游与分流路径只有取得证据才显示；当前部分字段保持未知。
- 原生分流模式使用固定内部端口，同一主机多个启用分流的实例需额外隔离。
- IPv6、多网卡、VPN、浏览器加密 DNS 等可能绕过预期入口，客户端接入仍需单独核对。

设备命名与分组、规则命中说明和趋势展示后续迭代。更大使用规模、长时间负载及不同网络的验证按具体环境记录，不能用旧版试验时长代替新版运行证据。

## 平台与性能

官方原生包仅支持 Debian 12/13 amd64；其他架构和系统需要独立构建及验收。Docker 兼容部署从源码构建，尚无公开预构建镜像。

既有 Unbound 严格 P99 对照未通过旧版重复性校准，相关记录保留在[历史结果](archive/2026-11/component-boundary-followup-results-2026-11-10.md)。这不证明新版退化，也不支持“已提升”或“全面无回归”的宣传。v0.1.0 发布以限定功能和安装/回退验证为依据，性能结论保持原有范围。
