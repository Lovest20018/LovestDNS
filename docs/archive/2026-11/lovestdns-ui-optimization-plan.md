# LovestDNS 控制台 UI 精细化优化方案

适用范围为原生版与集成容器共用的 `integrated/frontend` 控制台。基线见 [控制台体验方案](console-ux-plan.md) 和 [导航与功能归属方案](console-navigation-ui-plan.md)。在保留六栏导航、旧 hash 链接、深链参数和现有权限模型的前提下，减少重复样式和首屏占用，缩短常见运维操作，改善手机和键盘交互。实际交付见 [v0.2.2 发行说明](../../releases/v0.2.2.md)。

## 分期与验收

| 阶段 | 改动 | 核对重点 |
| --- | --- | --- |
| P0 · 设计系统与壳层 | 归并 `suite.css` 的基础样式和响应式规则，收紧顶栏，完善主题与账户菜单 | 明暗主题的文字对比度，顶栏高度，点击外部、Esc 和切页时的菜单行为 |
| P1 · 概览与广告过滤 | 复制 DNS 监听地址，保留探针结果，按严重度归并告警，提供规则占用、订阅筛选和转永久 | 探针跨页与过期逻辑，失败域名下钻，过滤动作的现有任务和权限边界 |
| P2 · 响应式与无障碍 | 恢复手机工具栏文字，改善长域名与设备备注布局，解释关键按钮禁用原因 | 320px 和 390px 无整页横向溢出，关键控件触控热区至少 44px，键盘焦点清晰 |

## P0 · 设计系统与壳层

### 颜色、字号和布局

- 在 `suite.css` 集中定义明暗主题的强调色、悬停色、浅色强调背景、聚焦环，以及实心控件的底色和文字色。保留 `--suite-blue` 作为 `--suite-accent` 的兼容别名。将蓝色残留底色和阴影换成主题变量。
- `.btn-primary` 和 `.tab-item.active` 共用实心色；深色界面的橙色链接和描边仍可使用较亮的强调色。白字配原提案的 `#c55b16` 实测约为 4.30:1，实心底色采用更深的暖橙。常规文字按 4.5:1 验收。[WCAG 2.2 对比度标准](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
- 按基础变量、壳层、通用控件、编辑器、业务与响应式整理样式。将品牌说明、侧栏页脚、设置提示、配置版本与编辑器辅助文字从 10–11px 提升至至少 12px。
- `.suite-topbar` 和 `.suite-brand` 统一为 58px。吸顶编辑器 `.suite-editor-toolbar` 复用顶栏高度变量，`#component-logs`、`#config-apply`、`#config-changes` 和 `.suite-settings-group` 的基础滚动偏移为 74px。进入设置组时按工具栏实际高度留出空间。主内容顶部留白为 20px，页标题下方留白为 14px。

### 顶栏交互

- 主题按钮循环切换跟随系统、明亮、深色，用 Monitor、Sun、Moon 区分当前模式，并提供对应的按钮名称。
- 点击账户菜单以外的区域或切页时收起菜单。按 Esc 收起菜单，并把焦点还给账户菜单的 summary。
- 保留 `h1` 的程序化焦点和移动导航抽屉关闭后的标题聚焦。

## P1 · 概览和广告过滤

### 概览

- 将 `ProbeSample`、`ProbeResult`、`ProbeObservation` 放入 `suiteContext.ts`，由 `SuiteProvider.tsx` 提供 `probe`、检查状态和 `runProbe()`。离页时允许已发起的请求继续完成。切换实例、角色或失去诊断权限时清理。样本在五分钟后，以及解析进程或配置任务发生变化时标为历史样本。
- 在 `SuiteDashboard.tsx` 的 `.suite-home-address` 旁添加复制按钮，复用 `copyText`。复制成功时就地显示「已复制」两秒，通过 `aria-live="polite"` 播报结果。普通 HTTP 使用浏览器的选区复制，浏览器拒绝复制时提示手动选择。多个地址按行写入剪贴板。
- 对失败样本，具有诊断权限时提供 `#/diagnostics?tab=query&domain=…` 链接，预填该样本域名。
- 核心异常、辅助组件异常、任务提交状态及最近失败任务按严重度排序。仅展示最高优先级告警，其余收进「另有 N 项待处理提醒」。只有一条告警时直接展示。

### 广告过滤

- `FilterEditor` 在 `.dns-filter-editor-footer` 即时显示排除空行及以 `#` 或 `!` 开头的注释后的规则行数、字符占用和进度。规则行数反映编辑内容，实际匹配数量由后端解析确认。后端按 UTF-8 字节限制为 16,384，容量条按相同口径，超过时在应用按钮旁说明。
- 「订阅与规则」用三个按钮筛选全部、拦截和白名单订阅，每项显示数量。按钮组支持键盘焦点，以 `aria-pressed` 表示当前筛选。
- 精确放行超过五条时提供按域名子串即时筛选和清空搜索。临时放行条目增加「转为永久」，沿用现有 `allow` 任务和 `permanent` 模式。

## P2 · 响应式、触控和可访问性

- 700px 及以下的文件及运行参数工具栏保留按钮图标和文字，关键操作的触控区域至少 44px。超窄屏允许按钮组换行。
- 查询记录及拦截列表使用等宽域名，长域名可断行。窄屏的设备备注和原始 IP 分行，备注加粗，地址使用较弱的字色和等宽字体。
- 保存或应用因读取／提交中、待核对、规则冲突、入口不可用或无修改而禁用时，在按钮附近显示原因。已有错误信息继续提供诊断细节。

## 逐批验证

每批使用仓库构建脚本组装共享前端，执行 TypeScript、Vite、ESLint 和单元测试。从仓库根目录运行下列命令。

```bash
python scripts/build-integrated-ui.py
npm --prefix .build/integrated-web test
node scripts/test-ui-optimization.mjs
node scripts/test-console-navigation.mjs
node scripts/test-home-console.mjs
node scripts/test-query-records.mjs
```

| 视口或输入 | 核对内容 | 通过依据 |
| --- | --- | --- |
| 1360px，亮／暗 | 顶栏和侧栏高亮，实心按钮与活动标签，概览的服务摘要和统计 | 首屏可见摘要与统计概览，验收文字对比度至少 4.5:1 |
| 390px、320px，亮／暗 | 编辑器、设置导航、精确放行、长域名和设备备注 | 页面无横向溢出，关键触控区域至少 44px，文字可见 |
| 键盘 | Tab 顺序，Esc 关闭账户菜单及抽屉，导航后标题焦点 | 可独立操作，关闭浮层后焦点返回入口或目标标题 |
