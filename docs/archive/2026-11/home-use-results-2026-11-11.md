## 组件与功能

复用冻结的定制 MosDNS、Redis `7.2.17`、Unbound `1.26.2` 与普通 DNSCrypt `2.1.20 combined`，没有重新编译组件。试验在仅有回环接口的私有网络运行，两条分流分别经过 Unbound DB 0／1 和 Redis，其中一条再经过 DNSCrypt 到本地 HTTP/2 DoH 夹具。

保存缓存并重启 Redis／两层 Unbound 后，两次首次查询获得 **2 次 Redis 命中、0 次 miss**。IPv4／IPv6、UDP／TCP、A／AAAA、两条分流、冷热问题的 **32 个组合、48 次预检查**通过。另以实际夹具计数确认，两条冷问题分别回源一次，两条热问题均不再回源。该配置为合成分流链路，不能替代所有生产模板。

完整试验含准备阶段共记录本地上游 4,757 次、DoH 4,761 次；DoH 全部使用 HTTP/2／ALPN h2，拒绝与 DNS 错误均为零。最终 Redis 自报 hit／miss 含预检查，不能用它代替持续阶段的整链缓存命中率。
