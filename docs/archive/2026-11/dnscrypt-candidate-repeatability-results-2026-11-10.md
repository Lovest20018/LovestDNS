# DNSCrypt 新版独立重复性补测结果

日期：2026-11-10，从 `d63aa38` 继续，执行[预先固定的方案](dnscrypt-candidate-repeatability-plan-2026-11-10.md)。**实际准备升级的 DNSCrypt 2.1.20 combined 候选，在 HTTP/2 TLS DoH 直连路径的三对自身重复性全部通过。** 六组的测量与资源条件均有效；本轮没有重跑旧版或执行新旧性能对照。

## 对此前异常的判断

[前轮换宿主机试验](component-crosshost-performance-results-2026-11-10.md)没有重现约 275 ms 的发送空档，本轮新版也没有。因此此前停顿不应作为“新版导致回归”的证据；环境或操作干扰仍是可能因素。原因尚未证实，原异常记录和该次测量无效的结论继续保留。

旧版前轮未通过的是第三对 P99 重复性：2.736964 / 2.483545 ms，相差 0.253419 ms，超过固定的 0.2 ms 门槛。六组旧版查询全部正确、零丢失、发送测量有效。这与更早的长发送空档是不同问题，不能据此认定旧版功能损坏，也不能直接推导新版表现。

## 固定输入与执行条件

本轮在同一 Debian 12 / KVM 宿主机运行，沿用摘要核对后的普通 combined 候选、普通发生器与 DoH 夹具，没有重编译或增加诊断埋点。combined 二进制 SHA-256 为 `f7b80a185b7c1e4ae58615e9225d5af6233f81523569237fbcd2cbd8d3c3a2c4`。冻结方法归档 SHA-256 为 `12193bd2aad2fb8b395024e44cf38b090ea7988564e0c1378076668326d60d70`，96 个源码输入逐项核对。

仅测 HTTP/2 直连，100 QPS、q64、GOMAXPROCS=2、去掉 NET_ADMIN，每组 30 秒。独立网络命名空间仅有 loopback，使用合成唯一问题；CPU 2–3、150% 配额、1 GiB 内存上限、Nice 10。独立监视器使用另一 CPU 组保存心跳及生产 DNS 探测。

首次准备检查在新网络命名空间中读取现场 host sysctl 路径时发生 FileNotFoundError，在任何查询前停止，阶段与成对结果均为空。保留原脚本、状态和完整日志后，将现场快照移到命名空间外预检，再启动正式补测；源码、制品、测量方法和门槛没有改变，没有重复已完成的查询组。

## 三对实际结果

| --- | --- | --- | ---: | --- |
| 1 | 1.717509 / 1.654422 | 2.877059 / 2.796121 | 0.080938 | 通过 |

| 3 | 1.727573 / 1.713254 | 2.920991 / 2.803697 | 0.117294 | 通过 |

三对 P95/P99 差值均不超过 `max(两者较小值×5%, 0.2ms)`，本轮实际门槛均为 0.2 ms。六组共发送并完成 **17,999 条查询，全部答案正确、零丢失**；第四组实际发送 2,999 条，其余各 3,000 条，全部满足预先固定的负载与时长容差，没有补发或删除样本。

TLS、HTTP/2／ALPN、直连路由、完整内核请求／响应配对、socket／抓包、发生器并发及未知报文检查全部有效。内核查询间距为 **6.033–25.687 ms**，满足 5–50 ms 范围，每毫秒桶最多一包。三个组各记录一次发生器相位重置，原始计数保留；没有追赶突发、并发跳过或未知报文，不据此筛除查询。

整个约 190 秒窗口内没有 CPU 配额限流或 memory max／OOM 增量，试验 cgroup 内存峰值 **79.04 MiB**。独立心跳共 **18,592 个样本**，最大间隔 **19.188 ms**；心跳只提供环境背景，没有用于修改分位数或过滤结果。

## 收尾与证据复核

**19 项收尾检查全部通过**：原服务进程、重启数及启动时间、发布及制品、配置规则、身份账户、230 个原备份文件、host resolver、系统启动标识和内核参数前后一致；源码、候选及控制脚本摘要保持不变。试验单元已停止，试验进程及命名空间内进程无残留。首次预检失败的单元亦确认进程已退出。

监视期间 **10 次生产 DNS 探测全部成功**，保存每次完整输出；收尾另一次探测成功。这只代表实际探测覆盖，不能等同于全部生产查询零失败。

私有证据归档 **81 个索引文件、887,766 字节**，SHA-256：`3f1c7349a996308847b61760110891ef46f51347067180cc19754b7d123fa6dd`。下载完成后独立复算文件与来源摘要、冻结方法、原始压缩查询计数与分位数、协议与发送条件、资源计数、三对差值、健康／心跳及保护状态，全部一致。归档排除实际缓存、TLS 密钥和现场配置内容，原始现场记录保存在被忽略的私有目录。

## 结论边界

本轮支持“新版 combined 在该路径、该窗口的三对自身重复性通过”。旧版与新版运行窗口没有交错，且旧版此前未通过全部校准，因此不能据两轮的绝对延迟判断新版更快、较慢或相对旧版无回归。CPU、RSS、P95/P99 的新旧正式对照仍未通过验收。

本轮没有扩展到 SOCKS、HTTP/1.1、其他负载或持久观察，没有修改默认组件、升级正式服务或推送发布。前轮 Redis 的独立通过结论保留；DNSCrypt 新版的本次通过也不等同于整个组件升级已经完成。
